What the app will never modify

Passwords, login emails, usernames, account IDs, order IDs, SKU selections, tags and other unmapped fields stay as imported. Existing payment data stays untouched unless you intentionally distribute synthetic test cards across selected Shikari/Valor profiles. Address editing stays local; optional ZIP lookups and Email Gen publishing only connect to the named service when requested. The app does not connect to your retailer accounts.

CSV/TSV/PSV preserve column names, order and data values. JSON/JSON Lines preserve existing keys and nested structures. TXT supports key=value records or one address per line. Formatting (such as CSV quoting or JSON indentation) may be rewritten; unrelated field values are not changed.

3. Cloudflare setup

Optional, for automatic activation from the installed desktop app. This only creates forwarding rules and verification requests. It never changes your website DNS or MX records.

Only enable Cloudflare Email Routing for sng.sarl. Do not change the MX records for slabsngrabsaco.com or any existing email service. Check email hosting before turning on Cloudflare Email Routing.
Cloudflare setup guide / DNS warning

1. Sign into Cloudflare and select the newly added sng.sarl domain. Do not modify your existing website domain slabsngrabsaco.com.

2. Check that sng.sarl has no existing incoming email service. Enable Email Routing on sng.sarl only, not your existing slabsngrabsaco.com domain.

3. Open → Compute → Email Service → Email Routing. Onboard sng.sarl, review its MX/TXT records, and enable routing only there.

4. Verify each forwarding destination. Create a token scoped to Zone Read, Zone Settings Read, Email Routing Addresses Read/Write, and Email Routing Rules Read/Write.

5. Unlock Email Gen with your Cloudflare owner token. Check setup, then publish drafts. Each alias forwards to just one verified inbox. Cloudflare currently limits standard routing to 200 rules per domain and 200 destinations per account.

These aliases do not create employee logins, inboxes or outgoing sender identities.
